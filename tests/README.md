# 测试与人工核对

资料成员负责独立标注与复核，技术成员把关键案例转为可重复测试。当前已增加contracts的Schema、模拟示例及危险输入检查；没有后端或真实模型验收通过声明。

运行方法见[契约说明](../contracts/README.md)。`test_contracts.py`仅检查接口；`contracts/backend-acceptance-cases.json`里的19个业务用例待后端实现后执行，不能把它们视为已通过。

参考案例：比亚迪2024可持续发展报告，来源见docs/DATA_SOURCES.md。至少记录指标、年度、原值、单位、范围、原文、PDF页码及印刷页。

必须覆盖：缺失不当0、年份错列、基期0、不可比不计算、伪造证据拒绝、unknown不自动扣分、两年调整一致、人工修改后旧结果失效。

人工答案仅用于测试；禁止企业名/页码分支硬编码生产抽取。模拟工具测试和真实模型效果分开统计。

当前契约v0.2.0：extract_metrics由后端提取并入库；主智能体不再提交指标候选。候选结构校验只测试后端内部边界。
