# 正式页面保存、版本与审计联调

日期2026-11-27；基于codex a0cfe96。使用正式SSR模板与business.js，业务数据均为隔离合成夹具，没有修改真实资料或调用模型。

## 发现与修复

1. 指标复核使依赖检查is_current=false后，SSR将检查完全过滤。用户无法在禁用模型的内测模式继续人工处理。现在保留失效检查的明确警告和普通复核表单，旧结果仍不计分；失效时隐藏依赖当前目标的处置表单，避免提交后404。只有用户明确保存复核才恢复当前标志，不自动认可旧结论。
2. 确定性400/422拒绝也会禁用整页写按钮。现在保留草稿并恢复提交前按钮状态，允许修改后重试；原本由服务器禁用的按钮仍禁用。409、运行占用和不确定网络结果继续要求核对，不能盲目重新提交。
3. 公网安全头对PDF也使用DENY/frame-ancestors none，阻止正式页同源内嵌证据。仅对PDF响应改为SAMEORIGIN和frame-ancestors self，外站嵌入仍禁止，任务与页面仍DENY。
4. 更新正式JS资源版本，完整重载页面后获取新脚本。
