# 主SDK与提取模型共享预算

默认额度0，缺少配置、未知模型、过期价格策略均拒绝请求。公网内测仍保持零模型预算，不因本功能自动开放。两种入口共用同一个SQLite费用账本：SDK仅持有一次性网关凭据，Messages请求通过loopback网关；提取模型的Chat Completions请求同样先过账本，再访问固定官方端点。重定向拒绝。

## 计量与暂停

金额为整数微元，1元=1,000,000微元。BEGIN IMMEDIATE原子预留防止两入口并发超支。已知用量按保守价格结算；超时、缺用量、坏响应保留请求预留，不能当0元重试。结算超预留或用量异常会暂停账本，需独立对账，不自动清除。

使用2026-11-28核对的官方人民币高峰/缓存未命中价：Flash输入2元/百万tokens、输出8元/百万tokens。缓存也按最高输入价保守计入；账本数值是费用上界，可能高于实际账单。来源：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ 。策略到2026-12-05失效，之后须重新核价再修改策略。

每次以1,000,000输入tokens和明确max_tokens预留，再按真实返回用量回退差额。限制文本请求不超过400KB、输出至多49,152 tokens；不支持图像和额外计费的托管工具，模型白名单为Flash及官方确认的旧Flash别名。Messages缓存输入与增量输出合并计量。SDK使用流式响应，网关缓冲至完整响应后转交，首轮进度可能延迟。

默认5元检查点、10元硬上限。实际计入+未决预留+下一次最大预留超过检查点，就在发送前暂停，因此可能不足实际5元就早停。SDK暂停状态waiting_budget保留原session_id、释放任务运行占用，不伪装completed；继续原会话仍须预算允许。未知状态与项目验收门槛不变。

## 配置（尚未在真实运行中启用）

- ESG_BUDGET_PATH：显式的持久账本路径，两入口必须指向同一文件；不要使用原件或backup路径。
- ESG_BUDGET_CAP_MICRO：0至10000000，默认0；真实使用须另有授权。
- ESG_BUDGET_CHECKPOINT_MICRO：默认5000000，最高10000000；提高检查点只能由操作人获得继续授权后改配置并重启，不自动提升。

不能通过换账本、删库或清除未知预留重置同一轮费用。主SDK子进程只能拿到网关临时凭据，不转发真实模型Key。网关服务仅绑定127.0.0.1；不连接公网前端，不记录请求正文、鉴权头或推理内容。

范围仅覆盖本程序的两个模型出口及上述价格假设，不管理同一个API Key被其他程序消耗的费用，也不是供应商账单保证。不支持的模型/协议/多模态必须拒绝，不能自行猜价格。

离线验证：先在独立环境安装锁定SDK/runtime 0.2.2rc2，再运行`python scripts/probe_budget_gateway.py --dsh-home /path/to/copied-sdk-home`。此探针创建新的合成session，仅连接本机合成提供器，使用假Key，不恢复或运行原业务session。它会在SDK home增加合成测试会话，须使用副本。
